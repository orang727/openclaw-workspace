📋 挂起任务工作流使用指南

基于 Lobster 工作流引擎 | 版本：1.0 | 创建时间：2026-03-16

📌 状态： 已完成 | 待测试

🚀 快速开始

1. 启用 Lobster 工具

在 OpenClaw 配置中添加：

{
  "tools": {
    "alsoAllow": ["lobster", "llm-task"]
  }
}

2. 安装 Lobster CLI

确保 lobster 命令在 PATH 中：

# 检查是否已安装
which lobster

# 如果未安装，参考 https://github.com/openclaw/lobster

📁 工作流文件

文件位置 ~/.openclaw/agents/main/workspace/workflows/hangqi-task-workflow.lobster
运行命令 lobster run --mode tool <workflow> --args-json '{}'

📝 工作流参数

参数 类型 必填 说明 示例
task_id string ✅ 任务 ID T001
work_order_id string ✅ 工单号 WO123
audio_ref string ✅ 录音引用 ID audio_456
confidence_threshold number ❌ 置信度阈值（默认 0.75） 0.75

🔄 工作流执行流程

阶段 A：理解与路由
Skill 1: 获取录音 → Skill 2: 意图识别 → Skill 3: 结果路由
阶段 B：跟单与执行
Skill 4: 跟单处理 → Skill 5: 业务执行 → 审批确认 → 任务归档

🛤️ 3 条路由路径

路由 1：确认上门

route_type: confirm_visit

动作：工单改约 → 新预约时间 = 当前日期 + 2 天 09:00

需要审批：否 | 执行模式：自动

最终状态：待履约

路由 2：用户询价/取消

route_type: price_or_cancel

动作：工单取消 → 取消原因：用户不需要了

需要审批：是（客服主管） | 执行模式：人工

最终状态：待取消审批

路由 3：其他意图

route_type: other

动作：创建跟单任务 → 任务类型：挂起跟单

需要审批：否 | 执行模式：自动

最终状态：待后续跟进

⚠️ 异常处理

场景 触发条件 处理方式 最终状态
录音获取失败 录音不存在、拉取失败、文件损坏 标记 need_human_review=true，跳过后续 Skills HUMAN_REVIEW
意图识别低置信度 confidence < 0.75 标记 need_human_review=true，execution_mode=manual HUMAN_REVIEW
工单取消审批 route_type = price_or_cancel 生成取消动作，need_approval=true，等待审批 WAIT_APPROVAL

📊 监控指标

指标 目标值 告警阈值
录音获取成功率 ≥ 95% < 90%
意图识别准确率 ≥ 90% < 85%
自动执行成功率 ≥ 95% < 90%
人工复核率 ≤ 15% > 20%
平均处理时长 < 2 分钟 > 5 分钟

🔧 调试技巧

1. 单步执行

lobster run --mode tool hangqi-task-workflow.lobster \
  --args-json '{"task_id":"T001","work_order_id":"WO123","audio_ref":"audio_456"}' \
  --stop-after skill1_fetch_audio

2. 查看中间结果

lobster run --mode tool hangqi-task-workflow.lobster \
  --args-json '{"task_id":"T001"}' \
  --verbose

3. 模拟测试

lobster run --mode tool hangqi-task-workflow.lobster \
  --args-json '{"task_id":"TEST001","work_order_id":"TEST_WO","audio_ref":"test_audio"}' \
  --dry-run
